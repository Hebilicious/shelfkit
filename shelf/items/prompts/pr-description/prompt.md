Write the description of a pull request for the current branch, from `git diff main...HEAD`.

- Open with one or two sentences on why the change exists.
- Then what changed, as a short list a reviewer can check against the diff.
- Then how it was verified: the commands run and what they showed.
- Close issue {{issue}} when one is given.

No marketing, no restating the diff line by line, and no mention of how the change was written.
